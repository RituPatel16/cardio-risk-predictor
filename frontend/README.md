# Vitalis multi-page frontend

Replace your current `src/App.jsx` with this version, and keep the included `src/components` folder and `src/index.css` in your existing Vite/Tailwind project.

Pages included:

- Home — landing page and call to action
- About — cardiovascular disease information and model diagnostics
- Risk assessment — the original four-step prediction flow
- Contact — project contact information and a demo message form

The Contact form is display-only until it is connected to an email service or backend endpoint. Update the placeholder contact details before publishing.
